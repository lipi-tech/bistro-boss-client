# Bistro Boss Client

The frontend of the Bistro Boss restaurant web app, built with React, Vite, and Tailwind CSS.

It connects to the backend API: https://github.com/lipi-tech/bistro-boss-server

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Create a `.env.local` file in the root folder and add your own Firebase and API keys
4. Run `npm run dev`
